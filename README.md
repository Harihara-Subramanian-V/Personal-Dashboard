## 🚀 Key Operational Systems

### 1. 🛡️ 3D Interactive Flip vCard (.vcf)
- Seamless 3D flip card with **RFC 6350 compliant `.vcf` export engine** for 1-click sync into Apple Contacts, Google Contacts, and Outlook.
- Instant 1-click full contact payload copy.

### 2. 🌍 3D Global Telemetry & Tactical Geolocation
- Real-time Three.js 3D sphere with node beacon coordinates mapping VIT Vellore, Chennai, and client telemetry nodes.
- High-tech latitude/longitude geolocation tracker with live targeting reticle.

### 3. 🧪 Interactive Laboratory Simulators
- **Image & Data Augmentation Studio**: Interactive computer vision studio running real-time spatial transformations, matrix rotations, Sobel edge filters, and Gaussian blurs on HTML5 canvas.
- **Air Ticket Reservation CLI**: Interactive terminal seat allocator and reservation state machine.
- **CTF Cyber Defense Lab**: Interactive decryption sandbox with Caesar ciphers, Base64 hash crackers, and binary payload decoders.
- **ESP32 Closed-Loop Kinematics Architecture**: Sensor fusion telemetry, MPU6050 complementary filtering ($\theta = \alpha(\theta + \omega \cdot dt) + (1-\alpha)\theta_{acc}$), and PID parameter inspector.

### 4. 📟 Root CLI Cyber Terminal
- Interactive command-line interface with custom command interpreter (`help`, `about`, `projects`, `open <project>`, `repo <project>`, `skills`, `hardware`, `papers`, `matrix`, `clear`, `contact`).

### 5. 📡 Side-Over Transmission Comms Deck
- Right-edge sliding cyber panel inspired by tactical HUDs.
- 1-click Gmail Web & Outlook Web composers, direct telephone telemetry quick-dial, and encrypted payload generator.

## 📦 Quick Start & Local Deployment

### 1. Clone Repository
```bash
git clone https://github.com/Harihara-Subramanian-V/Personal-Dashboard.git
cd Personal-Dashboard
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Production Build
```bash
npm run build
```
