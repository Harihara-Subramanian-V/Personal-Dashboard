## 📦 Local Development

### 1. Clone & Install
```bash
git clone https://github.com/Harihara-Subramanian-V/Personal-Dashboard.git
cd Personal-Dashboard
npm install
```

### 2. Run Dev Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
